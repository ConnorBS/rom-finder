Writing an Extension

Extensions are single .py files. The goal is simple: when a user searches for a game, they should see it in results and be able to click Download immediately — no extra browsing steps.

Implement three methods: search() returns one result per game, get_files() fetches the game page and extracts the direct CDN URL as a single-item list, and get_download_url() returns that URL. Override download_file() only if you need to refresh a signed token at download time. 

EXTENSION_INFO = {
    "id": "my_source",
    "name": "My Source",
    "version": "1.0.0",
    "type": "rom_source",
    "author": "you",
    "description": "Downloads ROMs from mysite.com.",
}

EXTENSION_SETTINGS = []  # list of {key, label, type, default, description}
