Documentation & API references

RetroAchievements Web API (V1) ↗

The V1 API ROM Finder uses today (retroachievements.org/API) — game lists, hashes, completion progress, achievement sets.

RetroAchievements API V2 docs (source) ↗

V2 (api.retroachievements.org/v2, JSON:API) exposes event award tiers (event → awards), per-achievement points/pointsWeighted, and an achievement's source game (achievement → games) — the data needed for the Goals event header tiers/points + per-achievement game/console. Verify reachability/auth in your environment with /api/diag/ra-v2?event=<id>.

rcheevos rc_hash ↗

Canonical source for each console's hashing algorithm (the basis for ROM Finder's RA hash matching).

CHD format check

Check & fix CHD container codec

Flag CHDs that use the Zstandard codec (cdzs/zstd) — RetroArch can play them, but its RetroAchievements hasher can't read them, so the game earns no achievements. When chdman is available it also re-encodes them onto a RA-safe codec (disc data verified identical, so the RA hash is unchanged). Opt-in; run it from the Scheduler (manual button or a daily slot).
